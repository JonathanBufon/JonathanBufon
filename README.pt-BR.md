## Projetos em Destaque

### CASIA — Plataforma Jurídica com Inteligência Artificial

Uma plataforma SaaS jurídica multi-tenant, desenvolvida para auxiliar profissionais do Direito no gerenciamento de casos, documentos e fluxos de trabalho assistidos por inteligência artificial.

**Destaques técnicos:**
- Arquitetura multi-tenant com isolamento de dados por organização e controle de acesso baseado em papéis.
- IA conversacional com streaming via SSE, gerenciamento de estados das mensagens e histórico persistente.
- Agentes de IA especializados por domínio e prompts configuráveis.
- Processamento multimodal de documentos e imagens.
- Jobs em segundo plano, filas e processamento assíncrono.
- Geração de documentos, rastreabilidade de fontes e auditoria.

**Stack:** Laravel · PHP · PostgreSQL · Redis · Livewire · Docker · OpenAI API

**Atuação:** Engenharia de produto, desenvolvimento backend e arquitetura de software.

**Site:** https://casiajud.com.br
